# **AIR QUALITY POLLUTION INDEX**

An end-to-end project that showcases etl pipeline of air quality pollution index data in Kuala Lumpur, Malaysia. The goal is to analyze the pollution quality, visualize and predict.

Multiple tools are used including:
- PostgreSQL - for data storage
- dbt (data build tool) - for data transformation
- Airflow - for orchestration
- Superset - for visualization
- Docker - for deployment and containerization

## Data Collection

Data is collected using API key from openweathermap.com
